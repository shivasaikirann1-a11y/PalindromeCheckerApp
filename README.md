# Palindrome Checker Application

## Overview

The Palindrome Checker Application is a console-based Java project that demonstrates multiple approaches to check whether a given string is a palindrome. A palindrome is a word, phrase, or sequence that reads the same forward and backward.

This project is designed to strengthen understanding of Java fundamentals and data structures by implementing different techniques such as string manipulation, arrays, stacks, queues, recursion, linked lists, and design patterns.

## Features

* Checks whether a string is a palindrome
* Demonstrates multiple algorithmic approaches
* Uses different data structures for implementation
* Compares execution time of different methods
* Implements strategy design pattern for flexible palindrome checking

## Technologies Used

* Java
* Core Java Data Structures
* Object-Oriented Programming Concepts

## Project Structure

### UseCase1 – Application Initialization

Displays the application title and version information when the program starts. 

### UseCase2 – Basic String Reversal

Checks palindrome by reversing the string using a loop and comparing it with the original string. 

### UseCase3 – Reverse String Comparison

Another implementation of reversing a string and validating if it matches the original. 

### UseCase4 – Character Array Method

Converts the string into a character array and compares characters from both ends using a two-pointer technique. 

### UseCase5 – Stack Based Method

Pushes characters into a stack and compares them while popping to check for palindrome. 

### UseCase6 – Queue and Stack Method

Uses both queue and stack data structures to compare characters from front and back. 

### UseCase7 – Deque Based Method

Uses a double-ended queue to compare characters from both ends. 

### UseCase8 – Linked List Method

Creates a linked list from characters, reverses the second half, and compares both halves. 

### UseCase9 – Recursive Method

Uses recursion to compare characters from the start and end of the string. 

### UseCase10 – Phrase Palindrome Check

Handles phrases by removing spaces and converting text to lowercase before checking palindrome. 

### UseCase11 – Object-Oriented Implementation

Implements palindrome checking using a separate class and method to demonstrate modular design. 

### UseCase12 – Strategy Design Pattern

Uses strategy pattern to switch between different palindrome checking algorithms dynamically. 

### UseCase13 – Performance Comparison

Compares execution time of reverse string method and two-pointer method using nanosecond timing. 

## How to Run

1. Install Java JDK.

2. Compile the program:

   javac UseCase*.java

3. Run any use case:

   java UseCase1PalindromeCheckerApp

Replace the number with the desired use case.

madam
